完善论坛反馈中的启动兼容、界面语言、服务健康检查与更新体验，并扩展客户端配置支持

- Windows 启动使用解析后的命令路径，支持裸 npx 对应的 .cmd/.bat 文件，并统一大小写不同的 PATH 环境变量
- 界面、通知和托盘支持简体中文与英文，默认跟随系统，手动选择可持久化；下游 MCP 原始诊断保留原文
- 新增可选主动探活与手动健康检查，默认关闭，连续失败时告警，不自动停止或重启服务；独立超时、忙碌跳过和启动代次校验避免影响正常会话
- 设置页支持手动检查 Moor 最新稳定版，版本比较忽略构建元数据；离线、限流或无效响应明确提示检查失败，更新由用户下载安装
- 新增 ZCode、MiniMax Code 配置支持，完善 Pi 原生 MCP、禁用配置、环境变量、工作目录与 SSE 导入兼容，并更新各客户端参考文档
